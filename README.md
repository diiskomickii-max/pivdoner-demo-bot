# ПивДонер — Демо-бот предзаказа (Demo Bot)

Интерактивный демонстрационный Telegram-бот предзаказа для кафе и стритфуда **«ПивДонер»**.
Специально подготовлен для показа возможностей заведениям, владельцам кафе и клиентам:

- 🧪 **Демо-режим (`DEMO_MODE=1`)**: заказы и админские кнопки статусов («✅ Принят», «🔥 Готовится», «🛍 Готов», «💰 Оплата подтверждена») приходят напрямую пользователю в личный чат — можно протестировать весь цикл «клиент + кассир/администратор» без настройки отдельной рабочей группы.
- 📖 **Встроенная инструкция**: кнопка «📖 Как работает бот» прямо в меню с пошаговым объяснением сценария.
- ⏱ **Авто-готовка**: фоновая смена статуса на «готовится» через 2.5 минуты для реалистичной демонстрации.
- 📞 **Контакт продавца (`SELLER_CONTACT`)**: быстрый переход на личный контакт разработчика/продавца бота.
- ☁️ **Готов к облачному деплою 24/7**: включает `Dockerfile`, `Procfile` и `render.yaml` для бесплатного хостинга на Render / Railway.

---

## 🌟 Возможности бота

- 📋 **Меню по категориям** с управлением количеством (+ / −) и корзиной блюд
- 🕐 **Предзаказ на удобное время** («как можно скорее», +20/40/60 мин, выбор своего времени)
- 💳 **Выбор способа оплаты**: онлайн по банковской ссылке / ЕРИП или наличными при получении
- 🔔 **Уведомления**: мгновенный push гостю при любой смене статуса заказа
- 📊 **Админ-функции**: отчёт по выручке и продажам за день, список активных заказов
- 👤 **Личный кабинет гостя**: история прошлых заказов, баланс бонусов
- 🎮 **Мини-игра «Кубик»**: ежедневный интерактивный розыгрыш бонусных баллов
- 🧹 **Автоочистка чата**: автоматическое удаление промежуточных служебных сообщений

## 🚀 Быстрый запуск локально

```bash
# 1. Установи зависимости
pip install -r requirements.txt

# 2. Настрой .env (скопируй из .env.example)
cp .env.example .env

# 3. Запусти бота
python bot.py
```

## ⚙️ Переменные окружения (`.env`)

```env
BOT_TOKEN=токен_от_BotFather
MANAGER_CHAT_ID=0
DEMO_MODE=1
SELLER_CONTACT=@xxlkkl
PAYMENT_URL=https://pay.example.com/pay?order={order_id}&sum={amount}
PAYMENT_ENABLED=1
```

## ☁️ Деплой 24/7

В репозитории настроены конфигурации:
- **Render**: файл `render.yaml` и `Procfile` (создай Background Worker)
- **Railway / Docker**: файл `Dockerfile`
- Подробные шаги описаны в [`DEPLOY.md`](DEPLOY.md).

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа, запуск поллинга aiogram 3 |
| `handlers.py` | Логика оформления заказа, статусов, админки и демо-режима |
| `keyboards.py` | Инлайн- и реплай-клавиатуры бота |
| `menu.py` | Меню кафе (шаурма, донеры, закуски, напитки) |
| `db.py` | SQLite база данных: заказы, клиенты, бонусы |
| `states.py` | Машина состояний FSM оформления заказа |
| `config.py` | Загрузка конфигурации из `.env` |
| `render.yaml` | Спецификация для Render Blueprint |
| `Dockerfile` | Docker-образ для контейнеризации |
